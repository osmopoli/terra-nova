Votre liste pour bien démarrer

    Choisissez votre propre code secret

    Le code reçu à l’accueil est provisoire. Choisissez-en un que vous seul connaissez : 6 chiffres faciles à retenir pour vous, mais pas 123456.

    Créer un compte sans adresse e-mail

    Vous recevez un identifiant (par exemple TN-482731) et vous choisissez un code secret de 6 chiffres. Vous pourrez aussi vous connecter avec votre numéro de téléphone.

    Pour vous connecter avec votre numéro. Il est chiffré et masqué pour les autres.

    6 chiffres, sans suite (123456) ni répétition (111111). Un mot de passe est aussi accepté.
